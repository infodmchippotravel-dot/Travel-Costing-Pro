    How to use it — step by step guide

    🚀 How to create a costing

    1. After you log in you see your Dashboard (statistics, recent costings and quick actions). Press ＋ New costing, then on the Costing page fill in the client name, travel date and currency.
    2. From the Transfers tab, select a transfer and add it to the package.
    3. Set the number of Adults and Children on the Costing page — every form uses these by default.
    4. In Services, tap SIC (Shared) Transfer, Private Transfer or Entry Tickets, select the item from the list, set how many with + and −, then press Add … to Package.
    5. Go to the PDF tab to preview the full quotation and download/print it.
    6. Press 💾 Save costing. The costing gets its number (COST-001, COST-002 …) automatically. On Saved Costings you can search, filter, sort, edit, print, download or delete it.

    🔑 Admin vs User

    Users log in with just their name. Their name is filled in as the Client Name on every new costing, and they see only the costings they saved. Admins log in with Admin Name + Admin ID + Password (the "Login as Admin" button on the login screen). Only admins can change rates, transfers, services and tickets, and admins see every saved costing.
